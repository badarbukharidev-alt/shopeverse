# ShopVerse

Modern responsive e-commerce marketplace UI built with HTML, CSS, JavaScript & Tailwind CSS — featuring product search, filtering, wishlist, shopping cart, product pages, ratings and smooth animations.

![ShopVerse Hero](hero.png)

## Features

- Responsive modern e-commerce UI
- Product search
- Category filtering
- Wishlist functionality
- Shopping cart
- Product detail pages
- Ratings and reviews
- Animated hero slider
- Mobile navigation
- Smooth hover and scroll effects
- Promotional deals and countdown
- Toast notifications
- Vanilla JavaScript frontend

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome
- Google Fonts

## Run Locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/your-username/shopverse.git
cd shopverse
```

No build tools, backend, or package installation are required.

## Preview

The project is a frontend e-commerce concept designed to demonstrate a polished, interactive shopping experience using modern web technologies.
